# AI 성능 측정 가이드

기말평가에서 "AI가 얼마나 정확한가"에 숫자로 답하기 위한 측정 방법이에요.
코딩은 거의 필요 없어요. 측정하고 엑셀에 적은 뒤 스크립트를 한 번 실행하면 발표용 표가 나와요.

| 측정 | 무엇을 | 결과 파일 |
|---|---|---|
| ① 체형 cm 측정 | 줄자로 잰 실제 폭 vs 앱이 잰 폭 | `results/body_summary.md` |
| ② 옷 종류 분류 | 옷 사진 30~50장에서 AI가 맞힌 비율 | `results/classify_summary.md`, `results/classify_per_image.csv` |

---

## ① 체형 cm 측정 정확도

### 준비물
줄자, 두꺼운 책 2권(또는 상자), 벽, 앱이 설치된 폰, 몸에 붙는 옷

### 실제 값 재는 법 (정면 폭 — 앱이 재는 것과 같은 기준)
앱은 사진에서 몸의 **정면 폭**(왼쪽 끝 ~ 오른쪽 끝 거리)을 재요. 둘레(줄자로 한 바퀴)가 아니에요.

1. 벽에 등과 뒤꿈치를 붙이고 똑바로 서요. 팔은 몸에서 조금 떨어뜨려요.
2. 다른 사람이 책 두 권을 벽에 수직으로 세워 몸 양쪽 끝에 살짝 닿게 대요.
3. 두 책 사이 거리를 줄자로 재요.

| 항목 | 책을 대는 위치 |
|---|---|
| 어깨 | 양쪽 어깨 가장 바깥 끝 (팔이 아니라 어깨뼈 끝) |
| 허리 | 몸통에서 가장 잘록한 높이 |
| 엉덩이 | 엉덩이에서 가장 넓은 높이 |
| 다리 | 서 있는 상태에서 **바닥 ~ 고관절**(다리가 접히는 높이) − **바닥 ~ 복숭아뼈** |

### 앱 값 재는 법
1. 앱 [AI분석]에서 실제 키를 입력하고, 같은 옷을 입은 채로 촬영해요 (촬영 가이드 따라가기).
2. 결과 화면의 어깨 · 허리 · 엉덩이 · 다리 cm 를 적어요. "측정 불가"면 빈칸으로 둬요.
3. **한 사람당 3번** 찍으면 "같은 사람인데 앱 값이 얼마나 흔들리는지(반복 측정 편차)"도 나와요.

### 기록 · 계산
1. `body_measure_template.csv` 를 엑셀로 열어 한 줄에 한 번씩 적고 **CSV UTF-8** 로 `body_measure.csv` 이름으로 저장해요.
   이름은 실명 대신 A, B, C, D 처럼 적어요 (몸 치수는 개인정보라 이 파일은 깃허브에 올리지 않아요).
2. backend 폴더에서 실행:
   ```bash
   python evaluation/eval_body.py evaluation/body_measure.csv
   ```
3. `results/body_summary.md` 의 표를 발표 자료에 붙여요.

| 결과 항목 | 뜻 |
|---|---|
| 평균 오차(cm) | 실제와 평균 몇 cm 차이 나는지 (작을수록 좋음) |
| 평균 오차율(%) | 실제 값 대비 몇 % 차이인지 |
| ±2cm 이내 비율 | 오차가 2cm 이하였던 비율 |
| 치우침 | + 면 앱이 크게, − 면 작게 재는 경향 (보정 근거) |
| 반복 측정 편차 | 같은 사람을 여러 번 찍었을 때 앱 값이 흔들린 정도 |

## ② 옷 종류 분류 정확도

### 사진 모으기
- 팀원 옷 · 쇼핑몰 사진으로 **30~50장** (종류마다 3~5장)
- 아래처럼 **정답 종류 이름의 폴더**에 넣어요. 폴더 이름은 영어 그대로 써야 해요.

```
backend/evaluation/clothes/
├── short_sleeved_shirt/    반팔 상의 (반팔티, 반팔 셔츠, 블라우스)
├── long_sleeved_shirt/     긴팔 상의 (긴팔티, 셔츠, 니트, 맨투맨, 후드티)
├── sleeveless/             민소매 상의
├── short_sleeved_outwear/  반팔 아우터
├── long_sleeved_outwear/   긴팔 아우터 (자켓, 코트, 가디건, 점퍼)
├── shorts/                 반바지
├── trousers/               긴바지 (청바지, 슬랙스, 면바지)
├── skirt/                  치마
├── short_sleeved_dress/    반팔 원피스
├── long_sleeved_dress/     긴팔 원피스
├── sleeveless_dress/       민소매 원피스
└── bag/                    가방 (핸드백, 백팩, 캐리어)
```
없는 종류는 폴더를 만들지 않아도 돼요. 사진 폴더는 깃허브에 올리지 않아요(용량).

### 실행
backend 폴더에서 (서버와 같은 라이브러리 필요 — `pip install -r requirements.txt`):
```bash
python evaluation/eval_classify.py evaluation/clothes
```
처음 실행하면 AI 모델(약 24MB)을 내려받아요.

| 결과 항목 | 뜻 |
|---|---|
| 소분류 정확도 | 반팔 상의 · 긴바지 … 까지 맞힌 비율 |
| 대분류 정확도 | 상의 · 하의 · 아우터 · 원피스 · 가방만 맞힌 비율 |
| 후보에 정답 포함 | 첫 답은 틀렸지만 후보 목록에 정답이 있던 비율 (앱에서 사용자가 고를 수 있음) |
| 인식 실패 | 옷을 하나도 못 찾은 비율 |
| 평균 처리 시간 | 사진 한 장 분류에 걸린 시간 (PC CPU 기준) |

`classify_summary.md` 에는 종류별 정확도, 대분류 혼동표(무엇을 무엇으로 착각했는지), 틀린 사진 목록이 들어 있어요.

> 참고: 앱은 배경을 지운 사진을 서버에 보내요. 이 측정은 원본 사진을 그대로 넣으므로 앱보다 조금 불리한 조건이에요.

## 발표에서 이렇게 쓰면 좋아요
- "체형 cm 측정은 4명 × 3회 측정에서 평균 오차 ○cm(○%), ○%가 ±2cm 이내"
- "옷 종류 분류는 ○장 중 대분류 ○%, 소분류 ○% 정확"
- 틀린 사례(예: 반팔 ↔ 긴팔 혼동)를 1~2개 보여주고 "후보 선택 기능으로 보완"이라고 설명하면 한계와 대응을 함께 보여줄 수 있어요.
