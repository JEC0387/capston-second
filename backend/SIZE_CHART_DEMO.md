# 개발용 사이즈표 시연

이 파일의 S/M/L/XL 어깨 단면 값(38/41/44/47 cm)은 **개발·시연용 가상 데이터**이며
어느 브랜드나 상품의 공식 실측이 아닙니다. 운영 Supabase/PostgreSQL에는 넣지 않습니다.

1. `backend` 폴더에서 기존 `.venv`의 Python으로
   `.\.venv\Scripts\python.exe demo_size_chart_server.py`를 실행합니다.
   이 명령은 메모리 내 SQLite에만 샘플 행 4개를 넣고 기존 FastAPI 앱을 8000번 포트에서 실행합니다.
   프로세스를 종료하면 샘플 DB도 사라집니다. 일반 `uvicorn main:app` 실행에는 샘플을 넣지 않습니다.
2. `http://127.0.0.1:8000/api/size-charts`에서 `totalCount: 4`, 브랜드
   `개발용 샘플 (공식 아님)`, 카테고리 `상의`, `measureType: 단면`을 확인합니다.
3. Android 에뮬레이터에서 앱을 실행합니다. 기본 `BackendApi.BASE_URL`은
   `http://10.0.2.2:8000`이므로 이 로컬 서버를 가리킵니다.
4. 인체분석에서 키를 입력하고 정상 전신 정면 사진을 분석합니다. cm 측정에 성공하면
   체형 분석 카드 아래에 사이즈 추천 카드가 나타납니다. 예를 들어 사진 기반 어깨 추정값이
   39.0 cm이면 기존 2 cm 여유 기준으로 M(41.0 cm)을 추천합니다.

실제 폰은 같은 네트워크에서 서버를 `--host 0.0.0.0`으로 실행하고,
`BackendApi.BASE_URL`을 개발 PC의 LAN 주소로 설정해야 합니다. 시연 서버는 인증·운영 데이터용이
아닙니다. 사진 분석에는 기존 모델/카메라 환경이 필요하며, 실제 착용 핏을 검증하지 않습니다.

현재 `size_charts`는 브랜드·카테고리 기준이며 상품 ID를 갖지 않습니다. 상품별 추천을 하려면
검증된 공식 실측 데이터, `productId`와 사이즈표의 연결, 상품 상세 화면의 해당 차트 조회가
추가로 필요합니다.
