# 계획 1 — 인체 분석 카메라

> 상태: **계획 확정 / 구현 전** (2026-09-26)
> 작업은 아래 "작업 순서"의 단계별로 진행하고, 각 단계마다 앱을 실행해 확인한 뒤 다음 단계로 넘어간다.

---

## 1. 목표

1. 사용자가 **정확한 체형 분석용 사진**을 찍도록 카메라 화면에서 실시간으로 안내한다.
2. 사용자의 **키를 기준으로 치수를 cm로 환산**하고, 옆모습 사진(선택)으로 **둘레를 추정**한다.
3. 치수로 **신체 지표 6개**를 계산해 체형 판정을 개선한다.
4. 측정할 때마다 **날짜별 기록**을 저장하고 **변화**("지난번보다 허리폭이 줄었어요")를 보여준다.

모든 계산은 폰 안에서 처리하며 서버(`backend/`)는 수정하지 않는다.

## 2. 확정된 결정 사항

| 항목 | 결정 |
|---|---|
| 카메라 | 앞/뒤 카메라 **둘 다 지원** (전환 버튼) |
| 음성 안내 | **넣는다** (안드로이드 기본 TTS) |
| 촬영 전 체크리스트 | **넣는다** (옷 / 배경 / 폰 높이) |
| 옆모습 촬영 | **선택** (건너뛰기 가능 → 둘레만 빠짐) |
| 측정 항목 | 어깨너비, 허리 폭, 엉덩이 폭, **팔 길이**, 다리 길이, 상체 길이, (옆모습 시) 가슴·허리·엉덩이 추정 둘레 |
| 상체 길이 정의 | **B안: 어깨 ~ 엉덩이 관절 (몸통 길이)** |
| 성별 | **입력받는다** → 지표 판정 기준을 성별로 다르게 적용 |
| 변화 판단 기준 | 폭·길이 **2cm**, 둘레 **3cm** 이상일 때만 "늘었/줄었어요" |
| 기록 | 측정할 때마다 **날짜와 함께 누적 저장** |

## 3. 전체 사용 흐름

```
체형 분석 화면
   │ (처음 한 번) 키 + 성별 입력 → 저장 (마이페이지에서 수정 가능)
   ▼
촬영 전 체크리스트 카드
   (몸에 붙는 옷 / 단색 배경 / 폰은 배꼽~가슴 높이)
   ▼
[1단계] 정면 촬영
   정면 실루엣 가이드 + 화면 문구 + 음성 안내
   → 모든 조건 충족 시 초록색 → 약 1초 유지 → 3·2·1 자동 촬영
   ▼
[2단계] 옆모습 촬영 (선택, [건너뛰기] 가능)
   옆모습 실루엣 가이드로 전환 → 동일 방식 자동 촬영
   ▼
분석 → 결과 화면
   체형 + cm 치수 + 신체 지표 + 추정 둘레(참고용) + 변화 문구
   → 기록 자동 저장 → [기록 보기]
```

## 4. 촬영 가이드 (실시간 안내)

### 4-1. 자동 검사 항목 (AI 포즈 인식 + 기울기 센서)

안내 문구는 **한 번에 하나만**, 아래 표의 **위에서부터 우선순위**로 보여준다.

| 순서 | 조건 | 판단 방법 | 안내 문구 |
|---|---|---|---|
| 1 | 폰 수직 | 기울기 센서로 앞뒤·좌우 기울기 | "폰을 똑바로 세워주세요" |
| 2 | 사람 있음 | 관절 인식 여부 | "화면 안으로 들어와 주세요" |
| 3 | 전신 보임 | 머리·발목이 화면 안에 있는지 | "발끝까지 보이게 뒤로 가세요" |
| 4 | 거리 (전신이 화면의 70~90%) | 머리~발목 높이 ÷ 화면 높이 | "조금 뒤로 가세요" / "조금 앞으로 오세요" |
| 5 | 가운데 위치 | 몸 중심의 가로 위치 | "왼쪽/오른쪽으로 조금 이동하세요" |
| 6 | 방향 | 정면: 좌우 어깨 깊이 차이·어깨 폭 비율 / 옆모습: 두 어깨가 겹쳐 보이는지 | "정면을 봐주세요" / "옆으로 돌아서 주세요" |
| 7 | 팔 | 정면: 손목이 골반에서 떨어져 있는지 (A자) / 옆모습: 팔이 몸 앞뒤로 튀어나오지 않는지 | "팔을 몸에서 살짝 떼주세요" / "팔을 옆구리에 붙여주세요" |
| 8 | 발 너비 (정면만) | 두 발목 거리 ≈ 골반 너비 | "발을 골반 너비로 벌려주세요" |

### 4-2. 자동 검사가 어려운 항목 → 촬영 전 체크리스트 카드
- 몸에 붙는 옷 (헐렁한 옷은 몸이 넓게 잡힘)
- 단색 배경 (윤곽 인식이 정확해짐)
- 폰 높이 배꼽~가슴 (위/아래에서 찍으면 비율 왜곡)

### 4-3. 자동 촬영
1. 모든 조건 충족 → 가이드 선 **초록색**
2. 약 1초 유지 → **3·2·1 카운트다운** (화면 + 음성)
3. 카운트다운 중 자세가 흐트러지면 **취소 후 다시 안내**
4. 기존 셔터 버튼은 유지 (수동 촬영 가능)

### 4-4. 음성 안내 규칙
- 문구가 **바뀔 때만** 말하고, 같은 문구는 몇 초 간격으로만 반복 (시끄럽지 않게)
- 뒤 카메라 + 삼각대로 혼자 찍을 때 화면이 안 보이므로 음성이 핵심

### 4-5. 앞 카메라 주의점
- 앞 카메라는 거울처럼 좌우가 뒤집혀 보이므로, AI 좌표를 뒤집어서 가이드와 맞춘다.
- "왼쪽/오른쪽으로 이동" 문구도 카메라 방향에 맞게 바꾼다.

## 5. 치수 측정 (cm 환산)

### 5-1. 기준: 키
- **1픽셀당 cm = 입력한 키(cm) ÷ 사진 속 키(픽셀)**
  - 예: 키 170cm, 사진 속 850픽셀 → 1픽셀 = 0.2cm → 어깨 210픽셀 ≈ 42cm
- 사진 속 키는 포즈 관절점(코~발뒤꿈치)이 아니라, **세그멘테이션으로 오려낸 몸 윤곽의 정수리~발바닥**으로 잰다. 관절점으로 재면 정수리가 빠져서 키를 작게 잡는다.
- 옆모습 사진은 거리가 다를 수 있으므로 **그 사진 안에서 따로 환산**한다.

### 5-2. 측정 항목

| 항목 | 사진 | 측정 방법 |
|---|---|---|
| 어깨너비 | 정면 | 어깨 높이의 몸 윤곽 폭 |
| 허리 폭 | 정면 | 허리 높이(어깨~엉덩이 60% 지점)의 몸 윤곽 폭 |
| 엉덩이 폭 | 정면 | 엉덩이 높이의 몸 윤곽 폭 |
| 팔 길이 | 정면 | 어깨→팔꿈치→손목 관절 거리 합, 좌우 평균 |
| 다리 길이 | 정면 | 엉덩이 관절 → 발바닥 |
| 상체(몸통) 길이 | 정면 | 어깨 → 엉덩이 관절 |
| 가슴·허리·엉덩이 두께 | 옆모습 | 각 높이의 앞뒤 몸 윤곽 폭 |
| 가슴·허리·엉덩이 둘레 | 정면+옆모습 | 폭과 두께로 **타원 둘레 (라마누잔 공식)** |

### 5-3. 추정 둘레 표시
- 제목: **"추정 둘레 (참고용)"**
- 설명: "실제 몸은 완벽한 타원이 아니라 ±5cm 정도 차이가 날 수 있어요"
- 옆모습이 없으면 "옆모습을 찍으면 둘레도 알 수 있어요" 버튼 표시

## 6. 신체 지표 6가지

비율은 단위가 약분되므로 **키 입력 없이도 계산 가능**하다. (키는 cm 표시에만 필요)

| 지표 | 계산 | 의미 |
|---|---|---|
| 역삼각형 정도 | 어깨폭 ÷ 엉덩이폭 | 상체 발달 / 균형 / 하체 발달 |
| 허리 잘록함 | 허리폭 ÷ 엉덩이폭 | 작을수록 잘록 |
| 상체 라인 | 허리폭 ÷ 어깨폭 | 작을수록 V라인 |
| 다리 비율 | 다리길이 ÷ 키 | 높을수록 롱다리 |
| 상하체 비율 | 몸통길이 ÷ 다리길이 | 허리가 긴 체형인지 |
| 체격 | 어깨폭 ÷ 키 | 넓은 / 보통 / 슬림 체격 |

- 각 지표는 "뚜렷함 / 보통 / 적음" 같은 **쉬운 말**로 판정하고 막대 그래프로 표시
- **판정 기준값은 성별(남/여)로 따로** 두고, `BodyIndexCalculator.kt` 한 곳에 모아서 숫자만 바꿔 조정 가능하게 한다.
- 기준값은 일반적인 값으로 시작 → **여러 명 실제 촬영으로 조정 필요**
- 기존 4체형(역삼각형/삼각형/모래시계형/직사각형) 판정에 새 지표를 반영
  - 예: "직사각형 · 다리 비율이 긴 편 · 슬림한 체격"

## 7. 측정 기록 & 변화

### 7-1. 저장
- 분석이 끝날 때마다 **기록 1건** 자동 저장 (SharedPreferences + JSON, 새 라이브러리 없음)
- 기록 내용: 날짜, 키, 성별, 모든 치수(cm), 둘레(없으면 빈칸), 지표 6개, 체형
- 잘못 찍은 기록은 **삭제** 가능

### 7-2. 변화 문구 (직전 기록과 비교)

| 차이 | 문구 예 |
|---|---|
| 2cm 이상 감소 | "지난번보다 허리폭이 2cm 줄었어요 👏" |
| 2cm 이상 증가 | "지난번보다 어깨너비가 2cm 늘었어요" |
| 2cm 미만 | "지난번과 비슷해요" |
| 둘레 (3cm 기준) | "허리둘레가 약 3cm 줄었어요 (참고용)" |

- 사진 측정 오차(1~2cm)로 생기는 **거짓 변화**를 막기 위한 기준
- 둘레는 **둘레가 있는 직전 기록**과 비교

### 7-3. 기록 화면 (새 화면)
- 날짜별 목록 → 누르면 그날 치수 상세
- 항목별 **꺾은선 그래프** (Compose Canvas로 직접 그림)
- 진입: 결과 화면 [기록 보기] 버튼, 마이페이지 "내 치수 기록" 메뉴

## 9. 작업 순서 (5단계)

| 단계 | 내용 | 확인 방법 |
|---|---|---|
| 1 | **촬영 가이드**: 실루엣, 실시간 안내, 기울기, 음성, 카메라 전환, 체크리스트, 자동 촬영 | 실제 폰으로 서서 안내·자동 촬영 동작 확인 |
| 2 | **키·성별 입력 + cm 치수** (폭, 팔·다리·몸통 길이) | 줄자로 잰 값과 비교 |
| 3 | **신체 지표 6개 + 체형 판정 개선** | 여러 명 촬영해 판정이 자연스러운지 확인 |
| 4 | **측정 기록 저장 + 변화 문구 + 기록 화면(그래프)** | 두 번 이상 측정해 비교 문구 확인 |
| 5 | **옆모습 촬영(선택) + 추정 둘레 (참고용)** | 줄자로 잰 둘레와 비교 |

## 10. 알려진 한계

- 추정 둘레는 타원 가정이라 **±5cm 정도 오차** 가능 → "참고용" 표시
- 신체 지표 판정 기준값은 초기값이며 **실측 데이터로 조정 필요**
- 헐렁한 옷, 복잡한 배경, 폰 높이는 자동 검사가 어려워 체크리스트에 의존
- 갤러리에서 올린 사진은 촬영 가이드를 거치지 않아 정확도가 낮을 수 있음
