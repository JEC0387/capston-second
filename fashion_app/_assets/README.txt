이 폴더(_assets)는 앱 빌드에 사용되지 않는 참고용 자료 모음입니다.
- ai_image_*    : ChatGPT 등으로 생성한 화면 시안 이미지
- demo_*        : 앱 데모/발표용 스크린샷
- ref_img_*     : 쇼핑몰에서 수집한 상품 참고 이미지
- doc_*         : 기획서 PDF 등 문서
- webpage_* / saved_webpage_files : 저장한 쇼핑몰 웹페이지
- home* / curr / cam_webcam : 초기 화면 참고용 캡처

실제 앱 리소스는 app/src/main/res/ 에 있으며, 이 폴더는 삭제해도 빌드에 영향이 없습니다.
