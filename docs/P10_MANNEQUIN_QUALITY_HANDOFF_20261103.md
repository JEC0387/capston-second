## 관절·연결 검증

합성 복합 조합에서 작은 손끝 표면14개 정점이 분리되는 문제를 발견해 손끝 두께/끝 곡선을 수정했다. 큰 허리·골반과 가는 허벅지의 조합에서는 손이 다리에 접촉하거나 경사가 급한 팔이 찌그러지는 문제도 검출했다. 팔 경로가 몸통·다리의 외곽을 피하고, 경로의 경사에 따라 간격을 더 확보하도록 했다. 경로에 수직인 두께를 유지하는 다구간 타원 튜브를 사용해 급경사에서 팔이 가늘어지는 수평 스윕의 한계도 보강했다. 기존 허용차를 완화하지 않았다.

생성 메시의 연결성을 런타임에서도 검사하고, 격자가 놓친 분리면이 있으면 해상도를 올려 재생성한다. 기본 해상도 최대112(추가 측정 행 최대4개)/최대300만 float 출력 한도를 넘거나 연결을 유지할 수 없으면 기존 오류 안내로 표시를 중단하며 원본 치수·옷장·사진은 유지한다. 실패한 모델을 정상 아바타로 표시하지 않는다.8개 기본/조절 샘플은 P9의6MB 출력 범위 이내를 검사하며, 극단 조합/재시도에는 최대12MB 출력 버퍼를 허용한다. 배열 용량도 이 한도를 넘지 않게 했다. 이는 전체 힙/직접 버퍼/격자/이미지를 합한 앱 메모리 측정치가 아니며 실기기 성능은 별도 확인해야 한다.

정확한 측정 행을 넣는 과정에서는 유효한 작은 면을 보존하고 거의 겹치는 격자 행을 병합했다. 검사 절단선은 double 계산/0.001mm 전이적 근접 용접/삼각형 모서리를 피하는5µm 절단 오프셋/폐곡선 검사를 사용한다. 기존 float 반올림이나 탐욕적 근접점 선택으로 조각난 교차선을 연결하는 수치 오류도 고쳤다. 알려진140cm 프리즘의 삼각형 경계 절단도 별도로 검사한다. 이 수치 처리는1.3cm 둘레 허용차를 늘리거나 실제 인체 정확도를 주장하는 것이 아니다.
