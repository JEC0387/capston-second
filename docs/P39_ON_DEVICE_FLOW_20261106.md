## 결과·저장·취소 계약과 한계

- 모델/작업 ID·입력 해시·3종 카테고리가 다른 응답, 손상된 PNG, 입력 바이트 그대로의 응답을 성공으로 표시하지 않는다. 이 검사만으로 생성형 출처나 시각적 품질을 증명할 수는 없다. 실제 추론 어댑터의 독립 실행 증거가 필요하다.
- 다른 의류/사진/배치로 바뀌면 기존 결과를 새 결과로 표시하지 않는다. 실패 재시도 때 이전 결과는 별도 표시로 유지한다. 저장 선택기를 연 뒤 결과가 바뀌어도 당시 PNG 바이트와 작업 정보를 저장한다.
- 취소/시간 초과는 native 연산 종료 보장이 아니다. 실제 작업이 반환할 때까지 추가 생성은 차단한다. 구현될 native 어댑터는 분리된 백그라운드 작업을 남기지 않는 구조여야 한다.
- 현재 결과/입력은 ViewModel 메모리에만 있다. 프로세스 종료 후 미저장 결과 복구는 지원하지 않는다. 명시적으로 저장한 파일은 사용자가 다시 열며, 파일 열기를 새 AI 생성 성공으로 표시하지 않는다. 자동 입력 영구 저장·사용자 데이터 마이그레이션 없음.
- PNG/JPEG만 지원하며 입력의 유효 인체·의류 의미 분석은 아직 모델 어댑터의 미완료 영역이다. `content://` 제공자가 클라우드 파일을 내려받는 동작까지 이 계층이 통제하지는 못한다. 이 계층에 HTTP 로더/사진 업로드는 없다.
- 저장 대상은 사용자 SAF 선택 또는 앱 files/cache 내부다. SAF 저장은 원자적이지 않으므로 실패/취소 시 일부 파일이 남을 수 있고 성공으로 표시하지 않는다. 기존 파일을 자동 삭제하지 않는다.

## 발견·수정한 통합 문제

1. **늦은 카드 로딩:** 기존 의류가 표시된 상태에서 다른 카드 로딩 중 마법봉 진입 시 늦게 완료된 선택이 고정된 배치를 바꿀 수 있었다. 진입 시 요청 세대를 무효화하고 카드/드롭 결과가 기존 스냅샷을 덮지 않도록 변경했다.
2. **구형 Android API 경계:** 새 색 공간 전처리의 API26 호출에 minSdk24 보호가 필요했다. SDK 조건을 추가했다. API24 Robolectric 런타임이 캐시에 없어 다운로드하지 않았으며 API24 실행은 미검증이다.
3. 메모리 부족 시 비교/저장 바이트 복사·파일 열기에서 성공 메시지를 내지 않도록 오류 경로를 보강했다. 실제 S25+ 저메모리 추론을 실행했다는 뜻은 아니다.
