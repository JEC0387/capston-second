# 1. P0 — AI 체형분석 촬영 및 사진 선택 버튼 오류

## 1.1 실제 발생 현상

실제 삼성 갤럭시에서 앱을 실행해 AI 체형분석 화면에 진입했습니다.

화면에는 다음 요소가 정상적으로 보입니다.

- 전신사진 업로드 영역
- 촬영 팁
- 사진 촬영하기 버튼
- 사진 선택하기 버튼

하지만 **'사진 촬영하기'와 '사진 선택하기' 버튼이 회색으로 비활성화된 것처럼 표시되며, 터치해도 작동하지 않습니다.**

이 때문에 사용자가 체형분석을 시작할 수 없습니다.

## 1.2 원인 분석

다음 사항을 확인해주세요.

- `BodyAnalysisScreen.kt`
- `BodyAnalysisViewModel.kt`
- `CameraPreviewScreen.kt`
- `AppNavigation.kt`
- `PrivacyConsentDialog.kt`
- AndroidManifest 및 권한 설정
- 사진 선택과 촬영에 연결된 callback
- 화면의 버튼 활성화 조건 및 상태 관리

특히 이전 체형분석 안정화 작업에서 개인정보 동의 처리를 보강한 이후, 버튼이 활성화되지 않는 문제가 발생했을 가능성을 확인해주세요.

단, 실제 코드를 확인하기 전에는 원인을 단정하지 마세요.

검토 항목:

1. 버튼의 `enabled` 조건

3. 개인정보 동의 여부에 따른 UI 상태

5. Compose 컴포넌트가 클릭 이벤트를 가로채는지 여부
6. 카메라 권한 요청 및 결과 처리
7. CameraX 화면 이동
8. Android Photo Picker 실행
9. ActivityResultLauncher와 Lifecycle 처리
10. 연속 클릭 및 화면 복귀 시 상태 초기화

## 1.3 요구 동작

### 사진 촬영하기

1. 사용자가 버튼을 누릅니다.
2. 필요한 안내 또는 동의가 있으면 표시합니다.

8. 분석에 실패하면 실패 이유와 재촬영 방법을 안내합니다.

### 사진 선택하기

1. 사용자가 버튼을 누릅니다.
2. 필요한 안내 또는 동의가 있으면 표시합니다.

8. 실패하면 사진을 다시 선택할 수 있어야 합니다.

- 버튼만 활성화하는 임시방편으로 해결하지 마세요.
- 촬영 또는 사진 선택 후 실제 분석까지 이어지는 흐름을 검증하세요.
- 기존 역삼각형 판정 편향 수정과 유효하지 않은 측정값 판정 보류 기능은 유지하세요.

**이 문제는 다른 개선 작업보다 우선해서 실제 코드 수정과 관련 테스트를 완료해주세요.**

# 2. P1 — 가상피팅 기능을 실제 생성형 AI 가상피팅으로 개선

## 2.1 실제 발생 현상

실제 스마트폰에서 가상피팅을 테스트했습니다.

현재 화면에서는 인물의 전신사진 위에 선택한 의류 이미지가 직접 겹쳐집니다.

사용자는 이미지를 드래그하거나 확대·축소할 수 있고, 마법봉 버튼도 누를 수 있습니다.

하지만 마법봉 버튼을 눌러도 실제로 옷을 입은 이미지가 생성되지 않습니다.

현재 확인된 현상:

- 데님 셔츠가 실제 착용된 모습이 아닌 이미지 오버레이로 표시됨
- 바지 사진의 사각형 배경이 그대로 나타남
- 신발 사진이 발 위치로 이동하지만 자연스럽게 착용되지 않음
- 기존 옷 위에 새로운 의류 이미지가 겹쳐져 부자연스러움
- 크기와 투명도를 조절해도 실제 옷을 입은 느낌이 나지 않음

현재 방식은 생성형 AI Virtual Try-On이 아니라 수동 이미지 합성에 가깝습니다.

## 2.2 기존 코드 분석

다음 파일과 관련 호출부를 먼저 분석해주세요.

- `VirtualFittingScreen.kt`
- `TryOnRepository.kt`
- `MusinsaClosetScreen.kt`
- 의류 이미지 및 배경 제거 관련 코드
- FASHN API 연동 관련 코드
- 인물 사진 저장 및 선택 코드

확인 사항:

1. 현재 마법봉 버튼의 정확한 동작
2. 자동 위치 조절과 실제 AI 합성 기능의 차이
3. FASHN API 연동 여부
4. API 키 설정 방식
5. 서버 또는 클라이언트의 요청 구조
6. API 응답 및 결과 이미지 처리
7. 실제 API 호출 실패 시 예외 처리
8. 상의·하의·신발 지원 범위
9. 비용이 발생하는 외부 API 호출 여부

기존에 FASHN 연동 코드가 있다면 우선 활용하되, 실제로 연결되어 있는지 검증해주세요.

## 2.3 최종적으로 원하는 가상피팅

**목표는 사용자가 선택한 옷을 인물 사진에 실제로 입힌 것처럼 자연스럽게 생성하는 것입니다.**

기대 동작:

- 사용자의 얼굴을 최대한 유지
- 헤어스타일 유지
- 신체 비율과 자세 최대한 유지
- 기존 의상을 선택한 의상으로 자연스럽게 대체
- 상의는 어깨·팔·몸통에 맞게 착용된 형태로 생성
- 하의는 허리·골반·다리에 맞게 착용된 형태로 생성
- 상품 사진의 사각형 배경 제거
- 불필요한 이미지 중첩 방지
- 신발은 실제 AI 지원 여부에 따라 처리
- AI가 만든 결과 이미지 저장
- 원본과 결과 비교

단, 생성형 AI 특성상 얼굴, 체형, 의류의 세부 디자인을 완전히 동일하게 유지하는 것은 보장할 수 없습니다.

결과 이미지가 실제 제품의 핏을 정확히 보장하는 것처럼 표현하지 마세요.

## 2.4 상의·하의 동시 피팅

가능하다면 여러 종류의 의류를 함께 적용하고 싶습니다.

예시:

1. 인물 사진 등록
2. 상의 선택
3. 하의 선택
4. 필요하면 신발 선택
5. AI 피팅 실행
6. 완성된 코디 이미지 확인

FASHN 또는 사용 가능한 모델이 한 번에 한 종류의 옷만 지원한다면, API 문서와 비용 및 이미지 품질을 확인한 뒤 단계별 합성을 검토해주세요.

한 번의 호출로 여러 의류가 지원된다고 임의로 가정하지 마세요.

여러 번의 API 호출이 필요한 경우 예상 호출 횟수와 비용을 알려주세요.

실제 비용이 발생하는 API를 테스트할 때는 불필요한 반복 호출을 피하고, 유료 호출 전에 사용자의 승인이 필요한 상황이라면 확인을 요청해주세요.

## 2.5 사용 방법 안내 UI 추가

가상피팅 화면 상단에 사용자가 기능을 쉽게 이해할 수 있는 안내를 추가해주세요.

### 원하는 문구

**"원하는 옷을 드래그해 배치한 뒤, 마법봉을 누르면 피팅이 완료돼요 ✨"**

다만 이 문구는 실제 마법봉 버튼이 AI 피팅을 실행하도록 연결된 경우에만 사용해주세요.

# 3. P1 — 내 옷장 화면 Collapsing Header 구현

## 3.1 현재 문제

내 옷장 화면에서 다음 세 가지 배너가 많은 세로 공간을 차지합니다.

1. 3개월 넘게 입지 않은 옷 알림
2. 부족한 옷 추천 배너
3. 무신사 랭킹 옷장 배너

배너 아래에는 다음 필터가 있습니다.

- 전체 / 내 옷 / 관심 옷
- 전체 / 상의 / 하의 / 아우터 등 카테고리

현재는 배너들이 화면 상단에 크게 표시되어 실제 옷 상품 카드가 절반 정도밖에 보이지 않습니다.

앱의 핵심 기능인 옷장 목록을 보기 불편한 상태입니다.

## 3.2 원하는 동작

**스크롤을 내리면 상단 배너 3개가 자연스럽게 위로 접히고, 위로 돌아가면 다시 펼쳐지는 Collapsing Header를 구현해주세요.**

구체적으로:

1. 처음 화면에 진입하면 배너 3개가 정상적으로 표시됩니다.
2. 사용자가 옷 목록을 보기 위해 아래로 스크롤하면 배너 영역이 자연스럽게 위로 사라집니다.
3. 배너가 사라진 공간에는 상품 카드가 표시됩니다.
4. 목록 중간에서 스크롤 방향만 바꿨다고 배너가 갑자기 나타나지 않도록 합니다.
5. 맨 위로 돌아오면 배너가 자연스럽게 다시 나타납니다.
6. 기존 배너 클릭 기능은 모두 유지합니다.
7. 상품 카드가 튀거나 겹치지 않아야 합니다.
8. 스크롤 속도에 따라 UI가 부자연스럽게 흔들리지 않아야 합니다.

## 3.3 UI 구성

다음 요소의 배치도 함께 검토해주세요.

- 내 옷장 제목
- 옷 개수
- 캘린더
- 오늘 입은 옷
- 상단 알림·추천 배너
- 전체 / 내 옷 / 관심 옷 필터
- 의류 카테고리 필터
- 옷 상품 목록
- 하단 주요 기능 버튼
- 하단 내비게이션

가능하면 **필터 영역은 상품 목록을 탐색하는 동안 계속 사용하기 편하도록 유지**해주세요.

배너 3개가 접히더라도 카테고리 필터는 정상 작동해야 합니다.

작은 화면에서도 옷 상품 카드가 충분히 표시되도록 조정해주세요.

## 3.4 구현 조건

- Jetpack Compose의 기존 스크롤 구조를 우선 분석
- 현재 화면에 적합한 Collapsing Header 패턴 적용
- 필요하면 LazyColumn 및 stickyHeader 검토
- 스크롤 위치 및 상태 유지
- 부드러운 애니메이션 적용
- 화면 전환 후 돌아왔을 때 스크롤 상태 확인
- 배너 클릭 이벤트 보존
- 기존 옷 목록 및 필터링 데이터 보존
- 디자인 색상과 기존 컴포넌트 스타일 유지
- 불필요한 화면 전체 재작성 금지

특히 배너가 단순히 투명해지기만 하는 방식이 아니라, **실제 레이아웃에서 차지하는 높이가 줄어들어 상품 카드가 더 많이 보이도록** 구현해주세요.

**둘째**, 가상피팅에서 의류 이미지를 단순히 사람 사진 위에 붙이는 것이 아니라, 지원되는 생성형 AI 모델을 활용해 실제 착용한 것처럼 자연스러운 결과를 제공해야 합니다. 실제 연동이 불가능하다면 그 이유와 필요한 설정을 명확하게 보고해주세요.

**셋째**, 내 옷장 화면을 아래로 스크롤하면 상단 추천·알림 배너가 자연스럽게 접혀 옷 상품 카드가 더 넓게 표시되어야 합니다.

단순히 코드 수정 완료라고 보고하는 데 그치지 말고, 실제 테스트 및 빌드 결과를 명확히 구분해서 전달해주세요.
