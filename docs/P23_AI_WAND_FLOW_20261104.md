# P23 AI 마법봉 — 실제 생성 경로 UX 및 결과 입력 일치 보정 (2026-11-04)

## 이번 코드 변경
- 사진 모드의 '마법봉'은 기존 `aiTryOnWand` 경로에서 생성형 AI 화면으로 이동한다. 서버 준비·선택 사진·선택 의류 검사와 **별도 전송/유료 승인**을 거쳐야 실제 POST가 발생한다.
- 사진의 옷 관절 위치 자동 정렬과 3D 아바타의 2D 옷 배치는 마법봉이라 부르지 않고 명확히 '위치 자동맞춤'으로 표시한다. 기존 `manualAutoAlign`/`avatarAutoFit` 동작과 저장소는 변경하지 않는다.
- 이전 실제 AI 결과를 다른 사진·옷의 결과로 잘못 보이지 않도록, 성공 결과의 원본 인물 URI 및 선택 의류 스냅샷을 메모리에 연결하고 현재 선택과 일치할 때만 결과/비교/저장을 노출한다.
- 기존 인증된 외부 FASHN 서버와 자체 GPU 서버 모두 결과 비교·저장 경로를 유지한다. 임의 생성 성공, 수동 이미지 합성 대체, 유료 서비스 자동 호출은 추가하지 않는다.
- Compose 회귀 테스트: 마법봉 진입, 미연결 시 생성 비활성, 사진 변경 후 이전 결과 숨김. 기존 승인 없는 자동 POST와 이미 통과한 옷장 테스트는 반복하지 않는다.

## 범위 및 남은 조건
- 실행 코드 변경과 테스트 추가: `VirtualFittingScreen`, `AiTryOnScreen`, `LocalVtonScreen`, `TryOnViewModel`, AI 흐름 및 발표용 피팅 UI 검사.
- 실생성은 아직 미검증. 외부 유료 API에는 인증된 HTTPS 프록시·개인 토큰·FASHN 키/크레딧과 사용자 개별 동의가 필요하다. 자체 모델은 허가된 CUDA, 가중치 및 라이선스 검토와 자체 서버 인증이 필요하다.
- 휴대폰/사진/키 입력, 외부 사진 전송, 운영 DB·Railway 변경, 결제는 수행하지 않았다. 기존 Preview/QA 18001을 삭제·초기화·재설치하지 않는다.
- 컴파일·CI·APK 최종 성공 여부는 GitHub Actions 결과로만 판정한다. 이번 커밋을 실생성 성공 또는 최종 납품으로 주장하지 않는다.
