## 재현과 구현

P37 기기 PNG에서 상의 허리·다리·신발이 좁아 원래 의류가 노출됐다. 당시 ML Kit 좌표는 보관하지 않았으므로 동일 기기 포즈를 재실행했다고 주장하지 않는다. 별도 절차 생성 이미지에 내부 관절과 바깥 윤곽을 독립적으로 지정해 같은 결함 유형을 재현했다.

- 기존 계산은 관절 중심 거리만으로 의류 폭·발 길이를 정했다. 새 `PhotoOutline`은 거의 균일한 테두리와 기준점에서 연속된 세 단면의 안정성·탐색 상한을 확인한 경우에만 기존 의상 윤곽을 반영한다.
- 상의 중간/허리, 바지 무릎/발목, 치마 밑단의 과도한 축소를 줄인다. 보정 상한이 원래 넓은 골반의 치마 폭을 줄이지 않도록 기존 폭을 하한으로 유지한다.
- 신발은 발끝 방향의 보이는 끝과 횡단 폭을 제한 범위에서 반영하고, 확장 후 양발 윤곽의 겹침을 다시 거절한다.
- 모호한 배경·상한 도달·불안정한 단면은 측정값으로 사용하지 않는다. 기존 관절 기반 추정과 불확실 안내를 유지한다.
- 기존 메시 접힘·왜곡 검사, 얼굴/손목 보호, 수동 이동·배율·회전, PNG 비교·저장 경로 유지. 의존성·인증·저장 형식·동기화·패키지 설정 변경 없음.
