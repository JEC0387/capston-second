## 품질 및 사용권

상의·하의와 양발 신발 반영, 얼굴·자세·배경의 대체적 유지를 두 담당자가 육안 확인했다. 심각한 전신 붕괴는 없지만 재킷에 플랩 주머니가 추가됐고 가슴 주머니·단추, 바지 허리 단추, 신발 앞코·굽·줄무늬 간격이 상품 참조와 다르다. 상품 동일성 보장 또는 전체 품질 PASS로 판정하지 않는다.

인물 입력은 PixelPanda AI의 CC BY 4.0 **합성 성인 이미지**이며 실인물 사진 품질·생체 정확도 검증이 아니다. 의류는 Met Public Domain 자료이며 역사적 의류를 사용한 시험이다. 출처와 변형 기록은 `generated-evidence/P54_ATTRIBUTION.txt`에 보존했다. P51의 기존 귀속 문서는 입력의 과거 출처로 그대로 보존했다.

API는 인물 업로드 `crop=false`, 생성 `keepForDays=1`, 상품 `validForDays=1`을 사용했다. 완료 상태는 고객 및 상품 삭제 요청의 정상 응답 이후 기록된다. 공급자 백업·보안 로그까지 즉시 삭제됐음을 검증한 것은 아니다. 로컬 검수 PNG·인수 증거는 API 결과 1시간 만료와 별개로 보존된다.
