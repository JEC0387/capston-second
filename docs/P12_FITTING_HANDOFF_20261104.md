## 실패 원인과 수정

- CI 41662051439는 Debug 빌드 성공 후 Android 404개 중 3개가 실패했다. 줄자 두 실패는 P11-final의 현재 부위/초안 캡처 콜백 및 고정 부위 선택 영역 수정이 P11에 없는 상태였다. 최신 P11의 key(selected)만으로는 해결되지 않았다. 검증된 콜백과 상태 보존을 통합했다. 저장 전 초안과 저장된 프로필을 구별하고 원본을 초기화하지 않는다.
- 피팅 테스트 타임아웃은 중첩 스크롤에서 가로 옷 목록의 부모가 노출되지 않은 상태로 클릭하던 경로였다. 부모 목록을 스크롤해 실제 노출을 확인하고 클릭한 뒤 기존 드래그·방향 버튼·저장·자동핏 검사를 그대로 실행해 통과했다. 타임아웃을 늘리거나 검사를 삭제하지 않았다.
- 지원하지 않는 cm 조합은 해당 모델의 검증 이유를 표시하며 기존 값을 유지한다.

## 실제 피팅 변경

1. 의류 이미지와 native Surface 위에 고정된 캔버스 좌표계의 단일 Compose 터치 수신 영역을 두었다. 보이는 의류 경계와 회전을 역변환해 터치한 의류를 고르고, 같은 좌표계로 이동·배율·회전을 적용한다. 옷 조작 중 native GLSurfaceView의 모델 터치를 잠그고, 별도 ‘모델 회전 확인’에서는 옷을 숨겨 모델을 확인한다. 옷 조작으로 돌아오면 정면/기본 줌으로 복귀한다. 실제 의복이 몸을 감싸며 회전한다고 표시하지 않는다.
2. 움직이는 이미지 자체에 제스처를 붙이지 않아 이미지 이동·회전으로 드래그 좌표계가 바뀌지 않게 한다. 큰 이미지가 부모 크기에 강제로 줄어들어 계산 비율과 달라지지 않도록 이미지 레이아웃을 처리한다. 방향 버튼, 배율, 회전, 사진/아바타의 별도 상태와 저장 경로를 유지한다.
3. `GarmentGeometry`가 기기 내부의 garment/cutout/image/original 후보를 확인한다. 최대 512px로 샘플링하여 alpha 경계를 계산한다. 읽기 실패, 완전히 투명하거나 불투명한 이미지를 유효 누끼로 표시하지 않는다. 원본 파일을 수정·삭제하거나 외부로 전송하지 않는다.
4. 자동핏은 투명 여백을 제외한 실제 보이는 경계의 비율로 배치한 뒤 전체 이미지 좌표로 환산한다. 기존 AvatarFittingStore schema1과 전체 이미지 기준 저장값을 유지하므로 임의 데이터 마이그레이션을 하지 않는다. 기존 저장 배치는 로드만으로 재정렬하지 않는다.
5. 상의/겉옷/하의/원피스의 너비와 길이를 다르게 계산하고, 비정상적으로 긴 이미지는 신체 구간에 맞춰 최대 높이를 제한한다. 누끼 경계를 확인하지 못했거나 여백이 너무 큰 옷은 자동핏을 적용하지 않고 수동 배치를 유지한다. 이미 정렬된 경우와 변경한 경우를 구분한다.
6. 자동핏 전 배치 스냅샷을 세션에 보존해 ‘자동 정렬 되돌리기’를 제공한다. 저장은 별도 사용자 동작이다. 화면 크기 변경 시 현재 배치와 되돌릴 배치를 함께 환산한다.
7. 비동기 이미지 읽기에는 요청 세대를 사용하여 늦은 완료가 최신 선택을 덮어쓰지 않게 한다. 저장 배치 복원 중 사용자가 새로 선택/해제한 슬롯도 덮어쓰지 않는다. 사진 포즈의 늦은 검출은 기존 P11-final 정책대로 옷을 임의 재배치하지 않는다.
8. 핵심 ‘정면 2D 의류 합성’ 안내는 항상 표시하고 긴 조작 설명은 펼침 안내로 이동했다. 기존 Cream/Camel/Brown 및 화면 내비게이션을 유지한다.

## 데이터·기술 한계

alpha 경계는 이미 잘라낸 이미지에서 투명 여백만 찾는다. 머리카락·피부·배경이 불투명 픽셀로 남으면 의류로 구별하지 못한다. 새 AI 누끼 모델이나 실제 3D 의류를 개발한 것이 아니다. 원본을 보존하므로 문제가 있는 옷은 옷장 사진을 사용자가 확인해야 한다. 불투명 원본은 수동 배치가 가능하지만 자동 누끼 성공으로 표시하지 않는다.

실제 S25+ 손가락/두 손가락 전달, native Surface 합성, GPU 성능, 재시작 후 업데이트 데이터 유지, 사진 URI 제공자별 권한은 실기기 미검증이다. Compose/Robolectric는 실제 Android GPU 검증이 아니다. 사진 모드의 프로세스 종료 후 자동 복원은 기존대로 별도 미구현이며, 아바타 의류의 명시적 저장/복원은 유지한다. 유료 API나 외부 사진 전송, 운영 DB·Railway 변경은 실행하지 않았다.

## 11월 16일 발표 전 필수 실기기 순서

1. 기존 Preview를 삭제/초기화하지 않는다. 옷장·사진·프로필을 먼저 확인하고 같은 패키지/서명·증가한 버전의 APK로 업데이트한다. Samsung 보안 기능을 끄거나 우회하지 않는다.
2. 키·몸무게 → cm 조절에서 허리/어깨/가슴/허리 순으로 줄자·숫자·±버튼을 섞어 조절하고 승인 저장/재진입을 확인한다. 취소는 기존 저장 프로필을 보존해야 한다.
3. 유효한 누끼 상의와 하의를 각각 올린다. 각 옷을 탭해 선택하고 한 손가락 이동·두 손가락 배율/회전·방향 버튼을 확인한다. 옷 조작 중 모델이 함께 회전하지 않아야 한다.
4. 모델 회전 확인에서 옷이 숨겨지고 저장 배치가 유지되는지 확인한다. 옷 조작 복귀 후 정면 정렬, 자동핏·이미 정렬됨 안내, 되돌리기를 확인한다.
5. 비대칭 투명 여백, 불투명 원본, 잘못된 누끼, 긴 바지, 원피스를 각각 확인한다. 머리카락이 남은 누끼는 성공한 자연스러운 착장으로 시연하지 않는다.
6. 이동·크기·회전 저장 후 앱 프로세스를 종료하고 다시 열어 아바타 배치를 확인한다. 화면 회전/작은 화면/큰 글자에서도 옷 선택과 저장 버튼에 도달하는지 확인한다.
7. 기존 분석·옷장·코디·인증·사진 피팅 회귀를 확인한다. 발표는 검증된 정면 2D 합성/수동 조절/자동 정렬/저장 흐름에 한정한다. 실제 3D 의복 시뮬레이션이나 GPU 서버 미준비 AI 생성은 시연 완료 기능으로 소개하지 않는다.
