## P3 체크포인트

  가슴/허리/엉덩이 둘레로 바꾸지 않는다. 키가 0.5 cm를 초과해 다르면 사진 추정값을 혼합하지 않는다.

- 기존 체형 분석 화면에 값별 출처·신체/키 비율·동일 정의의 사진/입력 차이를 표시한다.
  기존 어깨 기반 사이즈 추천은 직접 입력한 어깨가 있으면 사용한다. 치수 출처를 표시한다.
- 입력의 키 대비 어깨·길이 합계 검사를 보완했다. 유효하지 않은 저장값은 사용하지 않지만
  원본 preferences를 자동 삭제하지 않고 수정 안내를 표시한다. 저장하지 않는 값은 기존처럼 세션만 유지한다.

- 실제 정면/측면 사진과 줄자 실측 쌍은 제공되지 않았다. 차이 요약 계산은 합성 단위 테스트로
  검증했으며 실제 사람에 대한 MAE·정확도 개선 수치를 만들지 않았다.

  검증 없이 한 장의 정면 너비나 측면 사진을 둘레 정답으로 합치지 않는다. 측면 측정은 미구현이다.
- P5/P6 연계는 공유 치수와 기존 어깨 추천/옷장 AI 진입 경로까지다. 상품별 복수 치수·핏 선호·

## P4 최소 3D 뷰어 체크포인트 (실기기 미검증)

- Android 내장 OpenGL ES 2.0/GLSurfaceView를 Compose AndroidView로 통합했다. 외부 렌더링
  라이브러리·모델 다운로드 없이 오프라인 사용하며 기존 앱 구조를 유지하기 위한 선택이다.
- 원본 코드로 만든 3D 삼각형 메시·표면 법선·깊이 버퍼·원근 투영·조명 셰이더를 사용한다.
  2D 이미지 회전을 3D라고 부르는 방식이 아니다. 3,744개 수준 정점과 변경 시 렌더링으로 제한했다.
- 정면/측면/후면, 드래그 회전, 핀치/슬라이더 확대, 어깨/허리/힙 표시 비율, 기본 모델 복귀를 제공한다.
  직접 입력/사진 출처를 표시하고 원본 측정값·추천값을 조절 슬라이더로 덮어쓰지 않는다.
- 둘레를 사용할 때 깊이/폭 비율을 가정한 타원으로만 시각화한다. 실제 깊이·얼굴·사지 복원과
  옷감 시뮬레이션은 구현하지 않았다. 관절 높이/표시 범위의 제한도 안내한다.
- OpenGL 미지원/초기화 실패 안내와 화면 수명주기의 pause/resume을 연결했다. 실제 GPU,
  컨텍스트 상실·저성능 기기·회전/확대 터치·발열/프레임률은 실기기 미검증이다.
- Android **274개 / 35개 클래스**, 실패·오류·건너뜀 0. APK·기기 테스트 코드 컴파일 성공.
  3D 정점의 Z축/법선/유한성/크기 제한/입력별 변화, 선택 화면 진입과 기존 갤러리 동의를 검증했다.
- 기존 갤러리 노출 위치 회귀를 발견해 초기 3D 버튼을 치수 입력 옆으로 옮긴 뒤 전체 통과했다.
  이 결과를 실제 Android GPU에서 모델이 정상 렌더링됐다는 증거로 사용하지 않는다.
