## 확인한 결함·회귀 제안

수정 전 줄 번호이며, 총괄 변경 후에는 최종 diff를 기준으로 다시 연결한다.

1. **프로세스 복원 시 의류 연결 소실** — `TryOnViewModel.kt:33,90-92,157`.
   `requestId/base/person`만 저장하고 `selectedGarments`는 빈 목록으로 재생성한다.
   GET으로 완료 결과를 받아도 `resultGarments`가 빈 목록이 되어 현재 의류 선택과
   일치하지 않거나, 의류 선택이 없는 상태에서만 잘못 맞을 수 있다.
   회귀: POST 후 응답 유실→SavedState 재생성→GET 완료; 원래 의류·원본 연결,
   추가 POST 0회, 토큰 비저장, 다른 의류 결과 비노출을 각각 확인한다.

2. **재조회 결과를 새 생성으로 표시** — `TryOnViewModel.kt:158`.
   `watch()`는 GET 복원 여부와 관계없이 결과 도착 시 `resultFromPreviousAttempt=false`로
   설정한다. 실제 새 POST와 과거 작업 재조회/화면 재진입을 구분하는 표시 회귀가 필요하다.

3. **저장 선택기 대기 중 결과 경합** — `LocalVtonScreen.kt:102-114,216-217`.
   저장 버튼을 누른 순간의 결과가 아니라 CreateDocument callback 시점의
   `currentResult`를 사용한다. 이전 결과 A가 표시된 동일 입력 재생성 중 저장 선택기를
   열고 그 사이 B가 완료되면 A 대신 B가 저장될 수 있다. 아직 실기기 재현한 결함은 아니다.
   회귀: A 표시→저장 선택기 열기→deferred B 완료→선택기 반환→실제 저장 픽셀/해시가
   선택 당시 A인지 확인. picker 취소·저장 실패 후 상태 정리도 확인한다.

4. **새 Parser 준비 오류의 안내 누락** — `LocalVtonRepository.kt:164-175`.
   P31 서버의 `parser_integrity_unavailable`, `cpu_not_approved`가 일반 생성 실패로
   표시돼 원본 사진 확인을 권한다. 생성 차단 자체는 정상이다. 운영자의 자산/라이선스/
   실행 설정 문제임을 구분하는 메시지 및 ready=false UI 회귀가 적절하다.

추가 보관 제한: 저장한 이미지를 사용자가 다시 열어도 사진 자체만으로 AI 생성 출처,
사용한 원본·의류·작업 ID를 검증할 수 없다. 별도 표시 상태로 취급하고 현재 생성 결과나
유효한 비교 쌍에 주입하지 않는다. 사진 영구 저장·URI 영구 권한을 자동 추가하지 않는다.

### P32 수정 후 읽기 전용 재검수

- 총괄의 수정에서 위 네 항목의 구현을 확인했다. 이 확인은 컴파일·테스트 통과 주장이 아니다.
- 새 저장 이미지 열기는 명시적 사용자 선택만 받고, 현재 AI 결과·원본·작업 ID에 주입하지 않는다.
  새 선택 파일 읽기 시작 시 이전 열린 이미지를 비워 실패를 이전 파일의 성공으로 오인하지 않게 했다.
- 추가 UI 결함을 총괄에 전달했다: 복원 작업이 완료돼 `pending=false`가 되면
  `LocalVtonScreen`의 선택 목록이 전달된 `garments`로 즉시 바뀐다. 전달 목록이 비었거나,
  여러 항목이라 `chosenId`가 초기화되지 않았다면 복원 의류가 사라져 결과·비교·저장이 숨는다.

  남는지, 사용자가 다른 의류를 선택하면 이전 결과가 숨는지 UI 회귀가 필요하다.
  총괄이 복원 선택 유지 경로를 수정했고 빈 목록/다중 목록 Compose 회귀가 GREEN03에서 통과했다. 실기기 검증을 대신하지 않는다.

- 총괄은 P32 최종 소스 SHA의 실제 XML/로그를 확인한 뒤 수정 항목과 집중 결과를 별도 인수인계에 기록한다. 이 표의 과거 PASS를 P32 신규 PASS로 합산하지 않는다.
- 새로운 실제 CUDA 출력·Android 수신·개인 사진 처리·실측 기준·실기기 자료가 없다면 해당 칸은 미검증으로 유지한다.
- 전체 CI/추가 GPU 조사/라이선스 수락/운영 배포/기존 데이터 초기화는 이 QA 문서의 수행 범위가 아니다.
