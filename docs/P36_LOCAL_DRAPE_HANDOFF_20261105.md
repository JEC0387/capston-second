  거절한다. 짧거나 넓어 구분이 불명확한 바지와 아우터도 자동 모드에서 거절한다.
  기존 수동 피팅에서는 계속 조작할 수 있다. 얼굴 기준점이 없으면 얼굴 보존을 보장하는
  것으로 오인시키지 않도록 자동 모드를 중단한다.
- 신발은 서로 분리된 위에서 본 한 쌍, 이미지 위쪽이 발끝인 자료만 지원한다.
  상품 사진의 고유 왼발/오른발 정체성을 인식하지 않고 이미지 좌우 순서로 배정한다.
  개별 신발·겹친 신발·측면 상품 컷은 자동 성공으로 대체하지 않는다.
- 얼굴 영역 보존과 손목 주변 피부색 추정만 제공한다. 팔 전체·머리카락 의미 분할,
  기존 옷 제거, 새 주름/그림자 생성은 없다. 피부색 추정은 실제 다양한 피부색에서 미검증이다.

  의류를 범용으로 분리하지 못한다. 전체 요청 중 하나가 부적합하면 부분 성공으로 표시하지 않는다.
- PNG는 최대 긴 변 2048px이며 실제 입력/캔버스에 따라 해상도가 달라진다.
  저장 이미지 다시 열기는 기존 로컬 파일 선택 기능이다. 사진 URI의 영구 권한이나
  새 영구 작업 기록/자동 복원은 추가하지 않았다.
- 개발 입력은 직접 그린 합성 인물·줄무늬 상의·바지·치마·신발이다. P35 단색 도형 결과를
